
# Task Management

A Task Management Application built using React.js.

## Technologies Used

* React.js
* JavaScript
* HTML
* CSS
* React Router DOM
* React Icons
* React Bootstrap
* Vite
* Local Storage

## Setup and Run

### 1. Clone the Repository

```bash
git clone https://github.com/Janu071/TaskManagement.git
```

### 2. Navigate to the Project

```bash
cd TaskManagement
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Run the Application

```bash
npm run dev
```

The application will start on the local development server.

## Build

To create a production build:

```bash
npm run build
```

## Deployment

To deploy the application to GitHub Pages:

```bash
npm run deploy
```
